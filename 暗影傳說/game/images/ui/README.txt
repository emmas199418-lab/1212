===== UI 圖片放置說明 =====

此資料夾用於放置介面相關圖片素材。

可選的 UI 圖片：
─────────────────────────────
  textbox.png         對話框背景（1280×200，建議半透明）
  namebox.png         角色名稱框（250×50）
  button_idle.png     按鈕預設狀態
  button_hover.png    按鈕懸停狀態
  hp_bar.png          HP 條背景
  mp_bar.png          MP 條背景
─────────────────────────────

若不提供這些圖片，遊戲會使用程式碼定義的顏色方塊作為替代，效果完全正常。
