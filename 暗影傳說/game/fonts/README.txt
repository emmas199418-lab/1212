===== 字型放置說明 =====

遊戲使用繁體中文，需要支援 CJK 字元的字型檔案。

建議字型：NotoSansCJK-Regular.ttc（Google Noto 字體）

下載方式：
  https://fonts.google.com/noto/specimen/Noto+Sans+TC
  或搜尋 "Noto Sans CJK TC" 下載後放到此資料夾。

檔名必須是：NotoSansCJK-Regular.ttc

若沒有字型檔案：
  Ren'Py 在 Windows 上會嘗試使用系統繁體中文字型。
  若顯示亂碼或方塊，請務必提供字型檔案。

其他可用的免費繁體中文字型：
  - 思源黑體 (Source Han Sans TC)
  - 文泉驛微米黑
  下載後重命名為 NotoSansCJK-Regular.ttc 即可使用。
